# EduCycle - Backend Foundation

This is the Spring Boot backend foundation for the EduCycle project.

## Project Details

- **Group ID**: `com.educycle`
- **Artifact ID**: `educycle-backend`
- **Package**: `com.educycle`
- **Java Version**: 17
- **Spring Boot Version**: 3.2.3
- **Port**: 8080

## Configured Dependencies

- Spring Web
- Spring Data JPA
- Spring Security
- Spring Boot Validation
- MySQL Connector J
- Lombok
- Spring Boot DevTools

## Running the Application

To build and compile the project:
```bash
mvn clean compile
```

To run the Spring Boot application:
```bash
mvn spring-boot:run
```

The application will start on `http://localhost:8080`.
